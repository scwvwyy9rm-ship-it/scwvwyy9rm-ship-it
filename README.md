# Hi, I'm Christoffer Runnholm

### Founder & Developer of JAR-NILS

I'm building **[JAR-NILS](https://github.com/scwvwyy9rm-ship-it/JAR-NILS)**, a local-first AI programming project focused on useful project knowledge, controlled action, and verifiable results.

The project began in **August 2026**, growing out of AI-assisted game development. I lead its direction and development through AI-assisted workflows, testing, and review.

## What I care about

- **Local-first AI:** use local computing where it is effective and cloud reasoning selectively.
- **Clear boundaries:** define what an assistant may read, change, and execute.
- **Evidence:** check results against the actual project instead of relying on model confidence.
- **Human control:** keep consequential decisions explicit and make failed changes recoverable.
